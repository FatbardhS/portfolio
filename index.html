Full-stack web app

BYPC — Build Your PC

A guided PC builder. You pick the case, motherboard, CPU, cooler, GPU, power supply, RAM and storage step by step, and each step only offers parts that fit what you already chose: socket, form factor, cooler height, GPU length, RAM type and power draw are all checked. A budget mode suggests the best compatible PC for a given price, using real shop prices.

  • Angular
  • Three.js
  • NestJS
  • TypeORM
  • PostgreSQL
  • Docker

Full-stack website + CMS

TARGET Shooting Range

Website and online shop for a gun store and shooting range in Gjilan, Kosovo. It has an animated intro, a scope crosshair cursor, a target you can score shots on, "View in 3D" product models, and session booking that emails the staff. The owners manage products, brands and bookings in their own CMS. Albanian by default.

3D configurator

Closet Studio

Design a wardrobe or cabinet in the browser and see it in 3D. Set the size, columns, shelves, drawers, doors, handles and finishes, click parts in 3D to edit them, and get a live price with a bill of materials and a cut list. Warnings flag problems like sagging shelves, and the whole quote exports to PDF.

  • React 19
  • TypeScript
  • Three.js
  • Tailwind CSS
  • jsPDF
  • Vitest
